a)Definir el concepto de estabilidad de un algoritmo de ordenacion. Luego indique su utilidad practica. Indicar referencia
	Concepto de estabilidad de un algoritmo de ordenacion.
	Un algoritmo de ordenacion se denomina estable si, dados dos elementos con claves iguales, despues de 
	ordenarlos tienen el mismo orden que tenian antes de la clasificacion.
	
	Utilidades practicas..
	1. Distinguir entre elementos iguales
		Todos los algoritmos de ordenacion utilizan una clave para determinar el orden de los elementos de 
		la coleccion, denominada clave de ordenacion.
		Si la clave de ordenacion es el elemento (completo) en si, los elementos iguales son indistinguibles,
		como enteros o cadenas.
		Por otro lado, los elementos iguales se distinguen si la clave de ordenacion se compone de uno o 
		varios atributos, pero no de todos, como la edad en una clase Empleado.
	2. La clasificacion estable es importante, a veces....
		No siempre necesitamos una clasificacion estable.
		La estabilidad no es una preocupacion si:
		* los elementos son iguales son indistinguibles
		* todos los elementos de la coleccion son distintos.
		Cuando se distinguen elementos iguales, la estabilidad es imperativa.
	3. Si nuestro o parte del algoritmo depende de una subrutina de ordenacion que debe ser estable.
	4. En una base de datos...
		donde los registros se ordenan por un atributo especifico, la estabilidad de un algoritmo de 
		clasificacion garantiza que los registros con el mismo valor de atributo se ordenen segun su 
		orden original.
	5. Los algoritmos de clasificacion estables son generalmente mas lentos que los inestables...
		Sin embargo en muchas aplicaciones, la importancia de la estabilidad supera al costo en rendimiento.
		La estabilidad es un aspecto importante de los algoritmos de clasificacion que garantiza la preservacion
		del orden y las relaciones entre elementos iguales.

	public static <T extends Comparable<T>> void ordenar( T [] A ) { 
		int n = A.length; 
		for ( int i = 0 ; i < n ; i++) { 
			int min = i; 
			for ( int j=i+1; j < n; j++) { 
				if ( A[j].compareTo(A[min]) < 0 ) {

	public static <T extends Comparable <T>> void ordenarMod (T [] A){
		int n=A.length;
		for (i=0;i<n;i++){
			int min = i;
			for (int j=i+1;j<n;j++){
				if (A[j].compareTo(A[min])<0){
					min=j;
				}
			}
			//En vez de hacer un cambio directo desplazaremos los elementos entre i y min-1 una posicion a la derecha
			//Primero guardamos el valor minimo
			T tmp = A[min];
			//Ahora desplazaremos
			for (int k=min; k>i; k--){
				A[k]=A[k-1];
			}
			//Insertamos el minimo en la posicion i
			A[i]=tmp;
		}
	}
